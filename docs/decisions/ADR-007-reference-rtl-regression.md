# ADR-007 — Fixed PicoRV32 RTL reference regression

Status: ACCEPTED for an experimental local feasibility workflow, 2026-10-22. User explicitly requested actual GitHub RTL simulation and system regression. This adds a reference profile; it does not replace the Blueprint's Ibex/Verilator acceptance or freeze the full simulation contract.

The tested Windows host can execute portable Icarus Verilog and xPack RISC-V GCC. Docker Desktop was started but the Linux engine returned HTTP 500; no Linux container execution is claimed. Use exact PicoRV32 revision `ef203c2b0a3fb793280f5114941416c425c5b461`, with original upstream testbench and firmware. Pin download digests and retain original source hashes. Use actual RTL CPU execution, not instruction emulation or generated transcripts.

The fixed CLI `npm run sim:reference` builds upstream firmware, elaborates RTL and runs independent oracles. It accepts only an output directory under workspace `artifacts/real-soc` and an optional reduced quick mode, with no arbitrary executable/source/profile arguments. Copy originals to the run directory; additive monitors record evidence without modifying original RTL. Modern GCC flags explicitly enable Zicsr/Zifencei. C firmware uses RV32IC without M, matching upstream Makefile intent; instruction assembly tests exercise M separately.

Native commands run through explicit argv in Windows Job Objects: 1 GiB per process, 2 GiB per job, 16 processes, kill tree on close, 120 s wall limit per command, 30 MB command log limit and 200 MB per VCD file. Assignment happens immediately after process creation, not suspended creation. These are resource limits, **not filesystem/network/OS isolation**. The reviewed reference is opt-in CLI execution; general imported RTL simulation remains disabled (HTTP 424). Do not promote this worker to a service for hostile inputs before the full sandbox gate.

Evidence uses a separate experimental schema 1.0, not the Blueprint simulation RunManifest. Add read-only `/api/v1/reference-regression` and content-hashed artifact download routes. Pin downloads to the exact report hash, require manifest membership, resolve within the artifact boundary and check content hash. This is local single-user evidence access, not RBAC or cryptographic attestation. Add an RTL Regression workbench view; existing project analysis and firmware/profile semantics are unchanged. Raw VCD is downloadable; Wellen navigation and exact waveform/source correlation remain unavailable.

MMIO timestamps are simulation ticks in ns (`tick_fs=1000000`), origin `simulation_zero`, sampled at AXI write response handshake. The memory-model-latched address/data decode is DERIVED. Fetch samples are bounded bus fetch addresses, not retired instruction PCs. Raw upstream CPU trace is retained separately. Negative-control failure is explicitly `EXPECTED_FAIL_DETECTED`, never a hardware PASS.

External GPL tools and firmware runtime have separate license review scope. Preserve source/license/download evidence; do not distribute `.tools`, upstream copies, ELF or archives as a cleared product release. See [license scope](../compliance/REFERENCE_SIMULATION.md) and [actual results](../test-evidence/real-soc/REPORT.md).
